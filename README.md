# ATLAS Anomaly Detection

Research code for anomaly detection on ATLAS/CERN detector data.

- [`atlas_anomaly_detection/`](atlas_anomaly_detection/) — main pipeline: algorithms, evaluation, model comparison, and analysis.
- [`anomaly-detection-lab/`](anomaly-detection-lab/) — standalone experiments covering 12 methods (DBSCAN, Isolation Forest, LSTM autoencoder, DAGMM, USAD, OmniAnomaly, Transformer, VAE, GAN, POT thresholding, RL thresholding).

See each folder's README for setup and usage.
